# WhaleYing Benchmark Lab — 研究流程规范

## 适用范围

本文件规范评测实验的设计、执行、记录和报告流程，在涉及以下工作时手动引入：

- 新建或修改评测实验
- 消融测试设计与执行
- 实验结果的整理、对比或报告

## 基准与模型清单（本项目实际使用）

- **基准**：factconsolidation（MemoryAgentBench，`ai-hyz/MemoryAgentBench`，Conflict_Resolution），档位 sh/mh × 6k/32k/64k/262k 共 8 个；每个档位 = 1 个 context（`max_test_samples: 1`）、100 题（单样本）。数据集版本/下载来源以 commit/hash 记录；`max_test_samples: 1` 是运行配置，不是数据集版本标识。
- **作答模型**：qwen2.5-coder:3b / 7b / 1.5b（Ollama 本地）、gpt-4o-mini、deepseek-flash。
- **抽取模型**：deepseek-flash（schema 严格遵守最佳）。
- **检索**：多字段 BM25（默认）。向量+RRF 的结论见下，须限定范围。

## 已有组件消融结论（限定表述）

- **向量 + RRF**：在当前 factconsolidation 测试配置中，已进行消融，**暂未观察到明确的成绩增益**。默认采用 BM25-only，并**保留向量检索作为可拆卸组件**，供后续在其他数据集或配置中重新验证。
  - ⚠️ 该结论仅适用于已测试的数据集、模型、配置和评分条件，**不推广为「向量检索本身无价值」**。

## 实验设计要求

在实验开始前，须明确记录以下内容：

| 记录项 | 说明 |
|--------|------|
| 实验目的 | 本次实验要回答的具体问题 |
| 实验假设 | 预期的方向性结论（可为空，但须说明原因） |
| 目标变量 | 本次实验改变的变量 |
| 评价指标 | 使用哪些指标、如何计算、数值越高/越低表示越好 |

**消融实验原则**：每次消融原则上只改变一个目标组件（如：只换抽取模型、只去掉向量 RRF、只换作答模型）。若因工程原因必须同时变更多项，须在实验记录中说明原因并标注结论的局限性。

**对照组一致性**：对比组之间须保持数据集版本、题目范围、评分标准、模型配置一致。无法保持一致的须明确列出并说明对结论的潜在影响。

## 实验可追溯性要求

每项实验必须记录以下信息，缺失任意一项则该实验结果不得作为有效数据引用：

| 记录项 | 说明 |
|--------|------|
| 模型名称及版本 | 精确标识：云端 `提供方:模型ID`（如 `openai:gpt-4o-mini`）；本地 Ollama 模型名 + digest/参数 |
| 模型调用来源 | API 提供方、base URL、本地模型摘要 |
| 模型实际标识 | 云端模型 API ID（如 `deepseek-flash`）可能是别名，不等于底层实际模型版本；能获取时记录 API 返回的实际模型标识、请求日期、提供方 |
| 代码版本 | Git commit hash（记录实验运行时所在 commit） |
| 工作区状态 | Git 工作区是否干净；若有未提交修改，**保存本次运行代码的 diff 文件（或记录其校验值）**，并注明该实验不能仅凭 commit hash 完整复现 |
| 提示词与流程版本 | 抽取 / 拆题（SRL route-1）/ 检索 / 作答分别记录的提示模板版本 |
| 实验配置 | 温度、上下文窗口、检索开关（BM25-only / 向量+RRF）、拆题方式 |
| 数据集名称及版本 | factconsolidation sh/mh × 6k/32k/64k/262k，来源与版本 |
| 运行次数 | 单次须注明；多次须保留每次原始分数（如 47/47/47），不得只存均值 |
| 运行环境 | 必要的软硬件版本（Python 版本、Ollama 版本等） |
| 资源消耗 | API 费用、Token 数、耗时；状态标「已测量 / 未测量 / 不适用」（空值或 unknown 无法区分是没发生还是没统计） |
| 评分结果 | 原始分数 + 指标名（官方 `substring_exact_match`；`exact_match` 为自算参考）+ 计算方式 + 优劣方向 |
| 运行日期 | `YYYY-MM-DD`；多次运行建议记录时间戳 |
| 执行人 | 谁运行了该实验 |

> 尤其 **代码版本（commit hash）和提示模板版本**：否则将来即使拿到同样的模型和数据集，也未必能复现当时的处理流程。

## 成果来源区分

实验结果必须明确标注来源类别，允许值为以下三项之一：

- **`new`**：本项目期间新运行的实验（如 3b 无记忆直测 0%（3 次全 0）、3b 有记忆 47%（3 次全 47，SRL 拆题后）、3b 单跳 89%），须按本规范**完整记录**全部字段。
- **`inherited`**：来自 WhaleYing-Memory 前身项目的既有结果（如 gpt-4o-mini 单跳 5 次均值 substring 93.2% / exact 91.0%，`1119-1`），**保留原始记录，缺失的字段标记为「未知」并注明原始来源**。不得为了套新格式而补造数据。
- **`reproduced`**：在本项目环境重新运行前身实验，记录本次复现的完整信息，同时保留旧实验信息，并说明环境差异。

**禁止**将 `inherited` 结果以任何形式描述或呈现为 `new` 结果；**禁止**为旧数据补造缺失字段。

## 消融实验命名规范

格式：`<基础系统>_ablate_<被移除组件>_<版本>`

示例：
- `whaleying_direct_baseline_v1`（无记忆直测：不装记忆层 + 原文截断 16k，非单变量记忆层消融）
- `whaleying_ablate_vector_rrf_v1`（去掉向量 RRF，BM25-only）
- `whaleying_ablate_extractor_model_v1`（抽取模型换 gpt-4o-mini）

每组消融须包含：完整系统基线（`baseline`）+ 移除组件后（`ablated`）+ 差值及百分比变化。

## 数据集管理

- 大型数据集（如 MemoryAgentBench 的 262k 原文/parquet）不得直接提交 Git，须记录获取方式、版本、校验值（SHA256）。
- 小型测试数据可合理管理，但同样须记录版本与校验信息。
- 复用前身项目数据集须注明来源并核实许可证。
- 预处理脚本须版本化管理，确保可从原始数据复现。

## 统计报告规范

- 多次运行时，同时报告均值 + 方差/标准差，并保留逐次原始分数。
- 计算置信区间须注明方法（bootstrapping / t 分布）和置信水平。
- 样本量不足（如 3 次运行）时，结论置信程度须与实际运行次数相符，不夸大。

## 结果文件规范

文件名：`<实验名>_<YYYY-MM-DD>_results.json`

最小必要字段（具体 JSON Schema 待定，不提前实现）：

```
experiment_id        实验唯一标识
source               来源类别：new | inherited | reproduced
model                模型名称（精确标识，见上）
model_version        模型版本 / Ollama digest
model_source         API 提供方或本地运行来源
code_version         Git commit hash
git_status           工作区是否干净（有无未提交修改）
prompt_version       提示词/流程版本（抽取/拆题/检索/作答分别记录）
dataset              数据集名称（factconsolidation_sh/mh_6k|32k|64k|262k）
dataset_version      数据集版本或 commit hash
config_ref           配置文件引用
runtime_environment  Python、Ollama 等必要版本
resource_usage       Token、费用、耗时（可记录未知）
runs                 运行次数
run_results          逐次运行原始分数及时间戳
scores               汇总（均值、方差/标准差）
metrics              指标说明（名称、计算方式、优劣方向）
timestamp            YYYY-MM-DD
notes                备注
```

## 禁止事项

- 未经实际运行，不得将数据标记为实测结果。
- 不得修改已归档的历史结果文件；修订须新建版本并注明原因。
- 多次运行时不得丢弃逐次原始分数、只存汇总。
- 不得在报告中省略指标的计算方式和优劣方向。
- 不得为 inherited 历史数据补造缺失字段。
- 跨档位/跨样本量的分数不得互相推断（例：262k 单跳首跑 73% `1117-21` 因漏抽偏低，修复漏抽复测 93.2% `1119-1`——同一档位差 ~20pp；跨档位/跨样本量更不能互推）。
